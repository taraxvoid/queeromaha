Which location bar style feels right?

Single bar, rounded ends, one location active at a time. Using the site's existing purple palette (#7c3aed active, #f9f5ff/#ddd6fe idle).

A — Seamless track

One continuous rounded "track" container; no gaps/borders between segments. Active segment gets a solid purple capsule that appears to float inside the track. Closest to a true segmented control.

All Benson Dundee Old Market Midtown

B — Spaced pills in a bar

Same rounded-end outer track, but each location keeps a little breathing room between it and its neighbors (visible gap, no dividers). Closer to today's individual filter-pill look, just enclosed in one outer shell.

All Benson Dundee Old Market Midtown

C — Divided segments

Classic hardware-style segmented control: thin vertical dividers between each segment, flush edges, only the outer corners rounded. Most literally "cassette button bar," just re-skinned in the purple palette instead of skeuomorphic plastic.

Note: on narrow/mobile widths the bar would wrap or scroll horizontally — happy to mock that separately once a style is picked.
